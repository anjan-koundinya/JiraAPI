# 🧪 Jira API Automation Framework

A lightweight BDD-based REST API testing framework built using **Java**, **Rest Assured**, and **Cucumber**, integrated with **Jenkins** and **GitHub**.

---

## 🔧 Tech Stack

- Java + Maven  
- Rest Assured (API testing)  
- Cucumber (BDD)  
- Jenkins (CI)  
- GitHub (Version control)

---

## ✅ Features

- Basic Auth with Jira API
- Create / Get / Update / Delete Jira Issues
- Reusable Step Definitions & Utility Classes
- Cucumber Reports
- CI pipeline with Jenkins
